## [1.0.0] - 2026-03-15

### Added

- MCP server with stdio transport for todo.txt task management
- List tasks tool - displays all tasks with completion status
- Add tasks tool - supports adding multiple tasks at once
- Complete tasks tool - marks tasks as complete with automatic date stamping
- Remove tasks tool - removes individual tasks or all tasks with boolean flag
- Update task tool - modifies task descriptions
- Auto-creation of todo.txt file when adding first task
- Comprehensive error handling with user-friendly messages
- Full TypeScript support
- Jest test suite with isolated temp directory execution
